# Version1 Optimization:


  1. Multi-Agent Pathfinding (MAPF)
   * Collision Avoidance: Trucks treat other moving trucks as dynamic obstacles.
   * Traffic Rules: Priority given to trucks carrying packages; empty trucks wait in "pull-over" spots to let loaded trucks pass.
   * Aisle Management: Preventing two trucks from entering the same narrow aisle from opposite ends.


  2. Predictive Docking & Reservation
   * Dock Claiming: As soon as a truck enters the RETURNING state, it "claims" a dock in the metadata. Other trucks immediately re-calculate to the next nearest dock,
     preventing race conditions.
   * Charge Balancing: If all trucks are idle, they distribute themselves across the warehouse layout to minimize the distance to the next potential task spawn.


  3. Advanced Battery Intelligence
   * Round-Trip Feasibility: Before accepting a task, the truck calculates: Dist(to_pickup) + Dist(to_drop) + Dist(nearest_dock). If Total_Dist > Current_Battery, it rejects
     the task even if it's above 20%.
   * Opportunity Charging: If a truck is at 70% and there are no active tasks, it goes to charge now rather than waiting for Low Power mode.


  4. Harmonious Task Allocation
   * Global Optimization: Instead of "Nearest Truck to Task," use "Minimum Total Fleet Travel." (e.g., Robot A is 5m away, but Robot B is 6m away and heading in that
     direction anyway—Robot B takes it).
   * Chain Loading: If two tasks have pickup points near each other, one truck is assigned both to reduce travel "deadhead" time.


  5. Visual Synchrony
   * Fleet HUD: A 2D overlay showing all 4 trucks' status (Battery, State, Destination) simultaneously so the user doesn't have to check the console.
   * Path Visualization: Ghost lines on the floor showing the intended path of each truck to visually confirm harmony.




# Version2 Optimization:


  1. Strategic Multi-Agent Pathfinding (MAPF+)
   * Spatial-Temporal Reservations: When a truck plans a path, it "reserves" its grid cells at specific timestamps. If Robot B's path would intersect with Robot A at
     Time=10s, Robot B automatically calculates a 1-second "buffer wait" or a side-step route before even starting to move.
   * Dynamic Re-Routing: If a user places a pickup point that blocks a narrow aisle while a truck is mid-transit, the entire fleet instantly recalculates to avoid the
     bottleneck.
   * Priority Hierarchies:
       * Emergency (Red): Critical battery trucks get right-of-way.
       * Productive (Blue): Trucks carrying packages have secondary priority.
       * Idle (Grey): Empty trucks must move out of the way into "virtual sidings" to let productive trucks pass.

  2. Global Task Auctioning (Market-Based Assignment)
   * Collaborative Bidding: Instead of the nearest truck grabbing a task, the TaskSystem runs a "mini-auction" for every new task:
       * Robot A bids: "I am 5m away but have 25% battery. Cost = High."
       * Robot B bids: "I am 10m away but have 90% battery and a straight line path. Cost = Low."
       * Result: Robot B wins because it maximizes long-term fleet stability.
   * Task Bundling: If two tasks are in the same quadrant, one truck will plan a "Multi-Stop" route (Pickup A -> Pickup B -> Drop A -> Drop B) to minimize "Deadhead" (empty
     travel) distance.


  3. Strategic Energy Load-Balancing
   * Predictive Feasibility: Every task assignment includes a "Return-to-Dock" safety buffer calculation. If a truck cannot reach Pickup + Drop + Any available dock with a
     10% reserve, it is disqualified from bidding.
   * JIT (Just-In-Time) Charging: If the fleet is idle, trucks don't just sit there. They analyze the warehouse layout and "Yield" the most central docks to trucks with lower
     battery, moving themselves to peripheral docks.
   * Opportunity Harvesting: If a truck is passing a dock while heading to a task and has 30 seconds of "slack time," it will stop and "top-up" for a few seconds if it won't
     delay the delivery.


  4. Flow & Throughput Intelligence
   * Congestion Avoidance: The PathFinder uses a "Heatmap" of fleet movement. If Aisle 1 is "Hot" (busy), the cost of traversing it increases, naturally pushing other trucks
     to take alternate routes to maintain flow.
   * Idle Staging: When tasks are zero, trucks don't return to docks if they have >80% battery. Instead, they move to "Staging Points" (the center of the 4 warehouse
     quadrants) to minimize response time for the next click.
